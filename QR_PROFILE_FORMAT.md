# OpenControl Client: QR профиля, формат v1

QR содержит обычный JSON в UTF-8, без URI-обёртки и без Base64:

```json
{"type":"opencontrol-profile","version":1,"ip":"vpn.example.org","port":4090,"login":"user","password":"example-password"}
```

Это демонстрационные данные, не реальные учётные данные.

| Поле | Тип | Правило |
|---|---|---|
| `type` | string | строго `opencontrol-profile` |
| `version` | integer | строго `1` |
| `ip` | string | IP или DNS-имя сервера, без схемы `https://`, до 253 символов |
| `port` | integer | необязателен; по умолчанию 4090; диапазон 1–65535 |
| `login` | string | непустой логин, до 1024 байт UTF-8, без NUL |
| `password` | string | непустой пароль, до 1024 байт UTF-8, без NUL |

Весь JSON — не более 2500 байт UTF-8. Используйте обычное JSON-экранирование и QR byte mode с кодировкой UTF-8. Логин и пароль не обрезать и не нормализовать. Неизвестные дополнительные поля игнорируются. Название профиля не включается: после сканирования клиент спрашивает только название, создаёт новый профиль и сохраняет пароль с шифрованием Android Keystore. Сертификат не доверяется автоматически: при первом подключении действует обычное подтверждение отпечатка.

QR содержит пароль открытым текстом. Передавать только доверенным получателям. JSON/изображение QR нельзя записывать в логи, телеметрию, публичные документы или репозитории. Сканер клиента передаёт между Activity только одноразовый токен; содержимое QR находится в памяти процесса.

## Готовый промпт для другого проекта

> Добавь экспорт VPN-профиля в QR-код, совместимый с OpenControl Client. QR должен содержать обычный JSON в UTF-8, без URL-обёртки и Base64. Формат: `{"type":"opencontrol-profile","version":1,"ip":"vpn.example.org","port":4090,"login":"user","password":"example-password"}`. Поля type/version имеют указанные фиксированные значения; ip — IP или DNS-имя сервера без схемы URL; port — целое 1–65535, необязательно (4090 по умолчанию); login/password — непустые строки до 1024 байт UTF-8, без NUL. Сохраняй Unicode, пробелы и специальные символы логина/пароля, используй стандартное JSON-экранирование. Размер JSON не более 2500 байт UTF-8. Название профиля не включай: импортирующий клиент запросит его отдельно. Генерируй QR в UTF-8, проверяй обратное декодирование. Не записывай учётные данные или изображение QR в логи, телеметрию или файлы без явного действия пользователя. При показе QR укажи, что он содержит пароль и предназначен только для доверенных получателей.
