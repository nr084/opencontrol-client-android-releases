# OpenControl для Android

Независимый VPN-клиент для Android, совместимый с Kerio Control. Подключайтесь к своей сети, сохраняйте профили разных серверов и учётных записей и переключайтесь между ними.

**Проект не является продуктом Kerio или GFI, не связан с этими компаниями и не поддерживается ими.** Названия Kerio Control, Kerio и GFI упоминаются только для указания совместимости.

В этом репозитории размещаются готовые APK-релизы и инструкции. Исходники приложения хранятся отдельно.

## Скачать

[Последний релиз и APK](https://github.com/nr084/opencontrol-android/releases/latest)

Требуется Android 8.0 или новее. APK включает arm64-v8a и x86_64. Версия 1.0.0 использует библиотеку OpenControl 0.1.0.

## Установка

1. Откройте страницу релиза и скачайте файл `OpenControl-1.0.0-release.apk` из раздела **Assets**. Архивы **Source code** для установки не нужны.
2. Откройте APK на Android. Если система попросит, разрешите установку из используемого браузера или файлового менеджера.
3. Установите приложение и откройте OpenControl.

## Подключение

1. Нажмите **Добавить** и задайте название профиля.
2. Введите IP-адрес или DNS-имя VPN-сервера, порт, имя пользователя и пароль. Параметры подключения выдаёт администратор вашей сети.
3. При желании включите **Запомнить пароль**. Для каждого профиля сохраняются собственные учётные данные.
4. Если сервер использует собственный сертификат, нажмите **Проверить сертификат**, сверьте SHA-256-отпечаток с администратором и подтвердите доверие. Отпечаток сохраняется отдельно для этого профиля.
5. Нажмите **Подключить** и разрешите создание VPN-подключения в системном окне Android.
6. После подключения отображаются название профиля, адрес сервера и **IP (VPN)**. Для завершения нажмите **Отключить**.

## Возможности

- Несколько профилей серверов и учётных записей.
- Сохранение паролей с шифрованием через Android Keystore.
- Сохранение подтверждённого отпечатка сертификата для каждого профиля.
- Русский и английский языки, выбранные по настройкам Android.
- Светлая и тёмная темы по настройкам системы.
- Статистика подключения и уведомление с кнопкой отключения.
- Разрешены скриншоты. В разделе **О программе** указаны версии приложения и библиотеки OpenControl.

## Обновление

Устанавливайте новый APK поверх существующего приложения: удалять его перед обновлением не требуется. Это позволяет сохранить профили и настройки.
